# 界面验收

- 用户反馈一处显示异常时，先对照已认可的 demo、MediaArchive 实际模板和同类真实页。比较实体关系、字段值、交互和布局。仅截图结构相似或单个样本通过时，按实际覆盖范围报告。
- Series 页首第二栏展示作品资料与有依据的成员统计，注明覆盖和来源；收藏状态与成员均分放在已收录作品总览，系列手填总评单列。Work 的个人标签放在简介附近，用颜色和组名与题材标签区分。Series 和 Work 的阅读页仅在完整面板成功渲染后收起底部原文，保留「原文件」和渲染失败时的原文回退。
- 关系页用总图呈现系列、Work、笔记和资源，再展示有方向的续作与改编以及笔记的确切目标。旧档无类型双链显示为无方向关联。同名、目录或同系列成员身份都不构成续作和改编证据。「结构」按已声明的层级和媒介组织；跨对象笔记保留一份并列出目标。
- 滚动异常用不同长度的 Series 和 Work，在实际调整过的宽窄 Obsidian 桌面窗口检查。反复滚到底、切换分区再滚、在非零滚动位置打开浮层并关闭，确认内容仍挂载、页脚可见且原页位置稳定。改动区块隐藏方式时复核阅读模式的高度测量，以及原文回退。改浮层编辑时在隔离笔记验证缩放保留草稿、取消、明确保存、并发修改保护、位置记录只保存该段，并确认正式库的打开偏好。
- Components 改版先对照 MediaArchive 已用的书库、影视库或同类配置。覆盖本机生效的所有正式入口和自定义页签，保留原始字段、筛选、排序与组件 ID，使用独立展示字段处理中文状态、颜色和关联短标题。实际点开海报、进行中、创作者、来源及笔记分类，核对样例条目和跳转。隔离环境缺少授权时记录限制，先完成静态检查、备份与回退准备，再在已授权正式窗口核验。
