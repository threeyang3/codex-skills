# 管理本机漫笺书库

用户提供书名和想做的事即可。先用漫笺 MCP（`manjian`）的 `search_library`、`get_series` 查找目标。查询、改名、排序和整理书架直接使用漫笺 MCP。从网盘添加时，再用百度网盘 MCP（`baidu-netdisk`）找文件。漫笺须运行且已启用「Agent 接入」。当前会话缺少工具时，提示用户在本机打开漫笺并使用加载了相应 MCP 的 Codex 会话。参数以已发现的工具为准，如有漫笺项目工作树，可查阅其中的 `docs/manjian-agent.md`。

## 从网盘添加

1. 核对目标作品、网盘目录和版本。默认归入唯一明确匹配的已有系列，书库中无匹配时创建对应系列。多个版本仍符合请求，或账号、系列无法唯一确定时，一次列出候选请用户选择。用用户指定的版本、目录和话数筛选，筛选后仍有多个版本才问版本。
2. 用 `list_sources` 确认漫笺连接的是对应百度账号。优先用百度 MCP 返回的精确路径传递文件。只有确认保留精度时才使用字符串形式的 fsid。核对话数范围的起止，全量添加时确认文件清单完整。已登记的同版文件计入覆盖范围。遇到跨出指定范围的整包或缺号，先说明范围差异。
3. 用 `preview_imports` 核验文件，在 `defaults` 或单文件参数中传已有的 `seriesId` 或 `newSeriesTitle`。默认 `download: false`，只登记远程条目。跳过可确认的已登记文件和批次内重复。已登记对象若出现版本冲突，保留原记录并报告。不同扫描版或章节有重叠的文件应按版本判断，不能仅凭话数判重。若清除重复后要提交部分文件，用剩余文件重新生成计划。
4. 对用户明确要求的添加，在预览无歧义后用 `commit_imports` 提交。用 `get_job` 查询已知 `jobId`，直到获得本次结果。提交响应丢失且没有 `jobId` 时，重放相同的 `planId` 和 `requestId`。区分新增、跳过和失败。清单不完整时说明缺口，征得同意后才提交该子集。

## 按话数排序与整理

- 对可识别的分话条目，以起始话数升序，保留「第011–020话」这类范围标题。添加时默认给新条目排好位置。用 `preview_library_changes` 和 `apply_library_changes` 提交 `kind: publication` 的补丁，`id` 填 `publicationId`，`sortOrder` 填起始话数；章节条目可标为 `chapter`。章节号与卷号分别处理。无法可靠识别话数时保留原记录并说明。
- 对明确要求的改名、归系列、排序、书架、欲读和书签操作，先预览，再应用到核对过的目标。只修改本次要求涉及的字段。
- 读回目标系列，核对新增范围、所属系列和排序。远程登记时确认本次任务未排入离线下载。回复只需说明新增、跳过和需处理的条目。
