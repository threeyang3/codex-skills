# 打包与转换

## 散图和漫画压缩包

- 先辨别每卷边界。封面、空白页、版权页、番外和跨页图按实际原书位置保留。封面名和文件名排序不一致、编号重置、各话目录嵌套、文件序号异常时，以目录、页码和相邻图为依据写出明确的页序。已有的正常跨页图不拆、不重新压图。
- 单卷散图用 `scripts/pack_cbz.py`。使用 MangaTag 的 Python 环境（需要 Python 3.11+ 和 Pillow），目标目录先存在，目标文件还不存在。默认只预览；复核页序和数量后用同样参数加 `--apply`。对命名混杂、有非图片文件或有嵌套的素材加 `--order pages.json`，文件是按阅读顺序排列的相对路径数组，例如 `["cover.jpg","第01话/1.jpg","第01话/2.jpg"]`。显式清单以所列图片为准，核对所有该卷正文、附页均已纳入。工具写出补零的页名，保留原图字节，并回读验证。多个卷分别处理。
- 已有 CBZ 直接打开。普通 ZIP 若确实是一卷可读漫画，现有页序正确，且没有需要解密或拆出的内层包，可以按原字节复制为新的 `.cbz`，随后用 MangaTag 验证。这样能保留已存在的 ComicInfo 和原书页名。只有 ZIP 签名本身不足以判断，需排除 EPUB、多卷套包和含嵌套压缩文件的容器。
- 对 MangaTag 可读取的单卷 CBR/RAR，预览 `mangatag convert-cbr SOURCE --output NEW.cbz`，复核后加 `--apply`。7Z/CB7、分卷包、加密包、无法直接读的 RAR，或包含多卷的压缩包，按[取件与解压](acquisition.md)安全解包，分卷后走散图流程。此路径遇到已有 ComicInfo、目录文件或其他附带资料时先读出并核对，避免丢失有效书目、锚点或原件独有内容。

## 明确要求 EPUB 或 MOBI 转 CBZ 时

先读取原书的元数据、目录和阅读顺序。仅当原文每个阅读单元都能对应到一张原始图片，且没有需保留的文字、裁切、覆盖层或交互内容时，用以下无损取图分支。排版或文字依赖复杂时，保留原格式，并说明需要另定渲染或人工整理方案。

- **EPUB**：用 MangaTag Python 环境运行 `scripts/extract_epub_pages.py SOURCE.epub EMPTY_PAGE_DIR`，查看 spine 到原图的逐页对应，再加 `--apply`。工具支持直接图片、只含一张图的简单 XHTML 和简单内嵌 SVG。还要抽查封面、页面边缘、跨页方向和依赖 CSS 的页面。逐页映射正确后用 `pack_cbz.py` 打包，按映射重建章节锚点，保留原 EPUB 到验收。
- **MOBI**：确认本机 calibre 可用且书未加 DRM。可尝试用本机 `ebook-convert SOURCE.mobi STAGED.epub` 生成临时 EPUB，再走上面的 spine 分支。转出的页数、顺序、封面、画质和原 MOBI 实际页面都要比对。该分支可能遇到合并页面、重复封面或重排，任何不符都应停在工作区。当前 calibre 没有可用的直接 CBZ 输出。
- 转格式会改变书内锚点。原目录的卷、章编号、标题和层级可复用，资源路径和索引按成品重建并复查。格式或版面无法保真时说明具体差异，保留原格式成品。
