# 整理漫画

把用户指定的漫画整理成卷次明确、页序正确、书目和章节可读回的文件。用同一套工作流接续下载、标注和归档，按任务范围决定交付到本地还是百度网盘。

1. **确定范围。** 先读已有任务记录、用户的目录习惯和明确的跳过项。确认作品、版本、卷次或话数，以及来源和目标。区分出版社、出版语言、扫描或电子、黑白或彩色、单页或跨页、分辨率及汉化来源。同名不同版本分开处理。若现有信息足以确定唯一版本，直接开始。仅在仍有会影响结果的歧义时问。
2. **取得素材。** 本地已有完整文件就复用。网盘文件先列出准确路径、卷数和大小，再下载到本次工作区。用户指定网页或分享、素材在网盘、档案加密时，读[取件与解压](references/acquisition.md)。记录来源与版本依据，访问口令留在取件环节。
3. **整理载体。** 散图及漫画压缩包默认交付 CBZ，已有 CBZ 直接标注。EPUB、MOBI 和其他可读电子书默认保持原格式，用户明确要求时才转换。按书内证据和实际阅读顺序分卷、核对封面、保留原图。需要拆包、重新打包或转格式时，读[打包与转换](references/packaging.md)。
4. **标注并验收。** 用 MangaTag 写入已核实的书目、版别及章节锚点。按同版相邻卷的命名习惯命名；重名时核对版本，识别不出卷号就保留原名。按[标注与验证](references/mangatag.md)导出副本并回读。成品和配套 `<成品文件名>.mangatag.json` 一起管理，书名变化时同步侧车文件名。
5. **交付和清理。** 本地任务交付到用户指定或可交付的独立目录。归档百度网盘时，按[百度网盘交付](references/baidu.md)暂存、验收、迁入正式目录。需要替换时，原件先进入本次的覆盖前备份，待正式目录复核后，再清理该备份、网盘暂存目录和本次本地工作副本。已有进度表或未处理清单时，更新同一份记录。最终说明格式、版别、范围、章节数、成品路径与清理结果，注明缺卷或仅侧车支持等实质限制。

## 漫笺暂缓入库

当前漫笺正在改进。漫画整理任务结束于文件交付与验收，漫笺入库等用户明确恢复后再执行。恢复后，使用已安装的 `manjian-library` Skill 和漫笺 MCP 核对云盘来源及系列。唯一匹配时加入已有系列，无匹配时创建系列。预览时核对版本、卷序和同版重复项，提交后回读确认结果。在线书目查询可在文件整理阶段独立完成。
